# Thư mục ảnh nhân vật dùng trực tiếp

Bạn cũng có thể chép bộ ảnh nhân vật hiện có vào đây. Website hỗ trợ cùng quy tắc tên file với `src/assets/character`.

Ảnh đặt trong `src/assets/character` được tự nhận khi build. Ảnh đặt trong `public/assets/character` có thể được thay trực tiếp mà không sửa code.
