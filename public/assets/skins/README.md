# ClassQuest character skins

Production uses exactly 60 WebP files: 6 roles × 5 armour tiers × 2 genders.

File pattern: `ROLE-TIER-GENDER.webp`

- Roles: `warrior`, `mage`, `cleric`, `explorer`, `guardian`, `bard`
- Tiers: `base`, `bronze`, `gold`, `crystal`, `divine`
- Genders: `male`, `female`

Armour changes at levels 10, 20, 30, and 40.
