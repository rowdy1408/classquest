RPG Character Asset Pack

This ZIP contains cropped PNG assets extracted from the generated design sheets.
Folders:
- heroine/: main heroine, female armor progression, heroine chibi versions
- class_armor/: six classes with male/female art and starter/advanced/elite armor crops
- chibi_armor_levels/: top-row chibi armor progression
- chibi_classes/: chibi class characters by gender
- sheets/: original full sheets for reference

Note: These are cropped assets from sheet layouts (not transparent-background cutouts).
You can use them as starter input assets in code or as references for later refinement.
