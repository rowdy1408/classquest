# Ảnh nhân vật ClassQuest

Đặt bộ ảnh nhân vật có sẵn của bạn vào thư mục này. Website sẽ tự tìm ảnh theo:

- Hệ: `warrior`, `mage`, `cleric`, `explorer`, `guardian`, `bard`
- Giới tính: `male` / `female` hoặc `nam` / `nu`
- Bậc giáp: `base`, `iron`, `steel`, `knight`, `crystal`, `divine`

Có thể giữ ảnh trong thư mục con theo hệ hoặc đặt trực tiếp tại đây. Ví dụ:

```text
warrior/warrior-male.png
warrior/warrior-female.png
warrior/warrior-steel-female.png
mage/mage-nu.png
guardian.png
```

Nếu bộ ảnh chỉ có một ảnh cho mỗi hệ, website sẽ dùng ảnh đó cho mọi cấp. Không cần import ảnh thủ công trong code.
